# 기술 세미나 자료

구성원 간 AI 기술에 대한 공통 이해를 돕기 위해 제작한 기술 세미나 자료입니다. RAG와 LLM의 기본 개념, 이를 BAXI에 적용한 사례, AI를 활용한 개발과 서비스 배포 흐름을 소개합니다.

상세 기술 문서가 아닌 소개 자료로, 기술 배경이 서로 다른 구성원들이 주요 개념과 실무 적용 맥락을 파악할 수 있도록 구성했습니다.

## 자료 구성

- **RAG 개념부터 BAXI 적용 사례까지**: RAG의 동작 원리와 BAXI의 검색·생성 구조
- **현업의 문제를 AI로 직접 해결하는 시대**: AI 기반 개발 방식과 현업 서비스로 이어지는 과정
- **BAXI 발표자료 일부**: 인사이트 포털, 정보 흐름, AI 활용 구조 및 답변 품질 평가
- **Demo Day 발표 대본**: BAXI의 문제 정의와 주요 기능, 시연 및 확장 방향
